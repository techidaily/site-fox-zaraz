**Release candidate version 3.10.0.1 of DEX 3 RE (red edition) is ready for download!**

Version 3.10.0.1 of [DEX 3 RE](https://tools.techidaily.com/pcdj/products/) is a [release candidate](https://en.wikipedia.org/wiki/Software%5Frelease%5Flife%5Fcycle) and as always, a free update for DEX 3 RE owners. The 3.10.0.1 update for[DEX 3 Pro’s](https://tools.techidaily.com/pcdj/products/) ‘little brother’ includes various performance improvements, bug fixes, and a slathering of new features. Most notably, support for all karaoke zip format variations, the ability to drag and drop to position in the sidelist (from any other list/search results), and small fonts for the karaoke singers screen.

The new DEX 3 RE 3.10.0.1 release has been thoroughly in-house and by a select group of DJs and we can report it’s been rock solid. 3.10.0.1 is considered a release candidate so if you have any issues you can roll back to the prior DEX 3 RE release on the [DEX 3 RE support page](https://tools.techidaily.com/pcdj/products/).

* Some fixes and changes to the Preferences/Configuration window
